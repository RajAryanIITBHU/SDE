# 5. Polymorphism: Compile-Time vs. Runtime & VTable Internals

## What is Polymorphism?
**Polymorphism** (Greek: "many forms") is the ability of an entity (function, operator, or object) to exhibit different behaviors depending on the context.

```
                           POLYMORPHISM
                                 |
                 +---------------+---------------+
                 |                               |
                 v                               v
       COMPILE-TIME (STATIC)             RUN-TIME (DYNAMIC)
      - Function Overloading             - Function Overriding
      - Operator Overloading             - Virtual Functions
      - Templates (C++)                  - Duck Typing (Python)
```

---

## 1. Compile-Time Polymorphism (Static Binding)

### C++: Function & Operator Overloading
```cpp
#include <iostream>

using namespace std;

class Complex {
public:
    double real, imag;

    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // Function Overloading
    void print() const { cout << real << " + " << imag << "i\n"; }
    void print(const string& prefix) const { cout << prefix << ": " << real << " + " << imag << "i\n"; }

    // Operator Overloading (+)
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }
};

int main() {
    Complex c1(3, 4), c2(1, 2);
    Complex c3 = c1 + c2; // Calls operator+
    c3.print("Sum Result");
    return 0;
}
```

### Python: Operator Overloading via Dunder Methods
*(Python does not support traditional function overloading by parameter types; it uses default arguments `*args, **kwargs` and dunder methods like `__add__`).*

```python
class Complex:
    def __init__(self, real: float = 0, imag: float = 0):
        self.real = real
        self.imag = imag

    # Operator Overloading for +
    def __add__(self, other: "Complex") -> "Complex":
        return Complex(self.real + other.real, self.imag + other.imag)

    def __str__(self) -> str:
        return f"{self.real} + {self.imag}i"


if __name__ == "__main__":
    c1 = Complex(3, 4)
    c2 = Complex(1, 2)
    c3 = c1 + c2
    print("Sum Result:", c3)
```

## 2. Run-Time Polymorphism (Dynamic Binding) & `vptr` / `vtable` Internals

In C++, dynamic polymorphism is achieved using `virtual` functions:

```cpp
#include <iostream>

using namespace std;

class Base {
public:
    virtual void speak() { cout << "Base speaking\n"; }
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void speak() override { cout << "Derived speaking\n"; }
};

int main() {
    Base* ptr = new Derived();
    ptr->speak(); // Outputs: "Derived speaking" (Resolved dynamically at runtime)
    delete ptr;
    return 0;
}
```

### How `vptr` and `vtable` Work Internally (Crucial Interview Topic!)

```
[ Object in Memory ]           [ Virtual Method Table (VTABLE) in Read-Only Data ]
+----------------------+       +-------------------------------------------------+
| vptr (8 bytes)       | ----> | &Derived::speak()                               |
| Base / Derived data  |       | &Derived::~Derived()                            |
+----------------------+       +-------------------------------------------------+
```

1. **Virtual Table (`vtable`):** A static lookup table generated by the compiler for every class containing at least one virtual function. It stores function pointers to the virtual methods.
2. **Virtual Pointer (`vptr`):** A hidden pointer inserted at the very beginning of the object instance pointing to its class's `vtable`.
3. **Execution Cost:** Invoking a virtual method requires one extra pointer indirection: `ptr->vptr->vtable[0]()` ($O(1)$ fast lookup).

## 3. Python Runtime Polymorphism (Duck Typing)
*"If it walks like a duck and quacks like a duck, it's a duck."*

```python
class Dog:
    def speak(self):
        return "Woof!"


class Cat:
    def speak(self):
        return "Meow!"


def make_it_speak(animal):
    # Dynamic dispatch resolves speak() at runtime
    print(animal.speak())


if __name__ == "__main__":
    make_it_speak(Dog())
    make_it_speak(Cat())
```
