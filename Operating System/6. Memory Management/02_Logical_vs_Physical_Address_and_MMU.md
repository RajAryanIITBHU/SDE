# 2. Logical vs. Physical Address & Memory Management Unit (MMU)

## 1. Logical (Virtual) Address
- **Generated by:** The **CPU** during program execution.
- **Perspective:** The process believes it has access to a dedicated, continuous block of memory starting from address `0x00000000` to maximum address.
- **Space:** The set of all logical addresses generated by a program is its **Logical Address Space**.

---

## 2. Physical Address
- **Generated by:** The **Memory Management Unit (MMU)** hardware.
- **Perspective:** The actual physical location (slot) in the RAM hardware chips.
- **Space:** The set of all physical addresses corresponding to logical addresses is the **Physical Address Space**.

---

## The Role of the MMU (Memory Management Unit)

The **MMU** is a dedicated hardware component on the CPU chip that performs **run-time address translation** from Logical Address to Physical Address.

```
       +-----+  Logical Address       +-------+  Physical Address     +-------+
       | CPU | ---------------------> |  MMU  | --------------------> |  RAM  |
       +-----+      (e.g., 346)       +-------+    (e.g., 14346)      +-------+
                                          ^
                                          |
                                   Relocation Register
                                      (Base = 14000)
```

$$\text{Physical Address} = \text{Logical Address} + \text{Base (Relocation) Register}$$

---

## Base & Limit Registers (Hardware Protection)

To prevent a process from accessing unauthorized memory:
1. **Base Register:** Holds the smallest legal physical memory address allocated to the process.
2. **Limit Register:** Specifies the size / range of the range.

```
CPU ---> Logical Address < Limit? ---> + Base Register ---> Physical Address in RAM
               | No                         |
               v                            |
         Trap: Memory Protection Error      |
```
