# 10. Page Fault Handling & Swap Space

## What is a Page Fault?
A **Page Fault** is a hardware trap / exception generated by the MMU when a process attempts to access a page whose **Valid/Present bit in the Page Table is `0`** (i.e., page is not currently in RAM).

*(A page fault is a normal, expected operating system event, NOT an error!)*

---

## 6-Step Sequence of Handling a Page Fault

```
1. CPU references memory -> MMU checks Page Table -> Valid bit is 0!
       |
2. Hardware triggers a TRAP to the OS (Page Fault Exception)
       |
3. OS pauses process, saves state, checks if address was a legal virtual address
       |
4. OS finds a free physical frame in RAM (or runs Page Replacement to evict a victim)
       |
5. OS schedules disk I/O to read the requested page from Swap Space into the frame
       |
6. Disk I/O completes -> OS updates Page Table (sets Frame #, Valid bit = 1)
   -> Restarts the exact instruction that faulted!
```

---

## What is Swap Space?
- **Swap Space** (or Pagefile in Windows) is a dedicated partition or file on the secondary storage (SSD/HDD) used by virtual memory as an extension of physical RAM.
- When RAM is full, the OS moves inactive pages to swap space (**Page Out / Swap Out**) and brings requested pages back into RAM (**Page In / Swap In**).
