# 3. Gaussian Mixture Models (GMM) & Expectation-Maximization (EM)

## 1. What is a Gaussian Mixture Model?
While K-Means performs **Hard Clustering** (each point strictly belongs to 1 cluster), a **Gaussian Mixture Model (GMM)** is a probabilistic generative model that performs **Soft (Fuzzy) Clustering**:

- Assumes all data points are generated from a mixture of $K$ distinct Gaussian distributions with parameters:
  1. Mean vector $\mu_k$
  2. Covariance matrix $\Sigma_k$
  3. Mixing weight / Prior probability $\pi_k$ ($\sum \pi_k = 1$)

$$P(x) = \sum_{k=1}^K \pi_k \cdot \mathcal{N}(x \,|\, \mu_k, \Sigma_k)$$

---

## 2. The Expectation-Maximization (EM) Algorithm

Because the true cluster assignments are **latent (hidden) variables**, GMMs are trained using the **EM Algorithm**:

```
1. Initialize parameters (μ_k, Σ_k, π_k) using K-Means.

2. E-STEP (Expectation): Compute the "Responsibility" γ_{ik} (probability that 
   point x_i was generated by cluster k):
      γ_{ik} = [ π_k * N(x_i | μ_k, Σ_k) ] / [ ∑_{j=1}^K π_j * N(x_i | μ_j, Σ_j) ]

3. M-STEP (Maximization): Update parameters to maximize the expected log-likelihood:
      μ_k   = (1 / N_k) * ∑_{i=1}^N γ_{ik} * x_i
      Σ_k   = (1 / N_k) * ∑_{i=1}^N γ_{ik} * (x_i - μ_k)(x_i - μ_k)^T
      π_k   = N_k / N      (where N_k = ∑_{i=1}^N γ_{ik})

4. REPEAT E-step and M-step until log-likelihood converges.
```

---

## 3. Python Implementation

```python
from sklearn.datasets import make_blobs
from sklearn.mixture import GaussianMixture

X, _ = make_blobs(n_samples=300, centers=3, cluster_std=0.8, random_state=42)

gmm = GaussianMixture(n_components=3, covariance_type="full", random_state=42)
gmm.fit(X)

# Soft probabilities for the first sample across all 3 clusters
sample_probs = gmm.predict_proba(X[:1])
print("Probabilities across 3 clusters for sample 0:", sample_probs.round(3))
```
